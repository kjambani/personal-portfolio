About Me

I’m a Software Engineer who loves building the infrastructure that makes AI actually work in production. I recently finished my MSc in Data Analytics with 1:1 Honours at the University of Galway, following two years at Merkle where I built everything from Java Spring Boot microservices to AWS-powered Node.js servers handling over 10k records weekly. I’m usually the person who automates away the manual headaches; for instance, I used Python to slash manual data extraction time by 70%.

Lately, I’ve been deep-diving into MLOps and Gen-AI through some pretty hands-on projects. I engineered an agentic job search engine using Antigravity and RAG with Claude 3.5 to automatically score job descriptions and rewrite resume bullets on the fly. My master’s thesis involved building a Reinforcement Learning agent in PyTorch that used geometric trading signals to boost win rates by 6%. I’ve even automated my own documentation by setting up an n8n workflow that watches my GitHub for code changes and triggers AI to write the user guides.

I’m now looking for my next challenge in Software, MLOps, or Gen-AI Engineering where I can keep building systems that are both reliable and intelligent.
